Расчёт несущей способности НВФ

Ветер/вес → кронштейн → анкер → профиль. Нормативные формулы (СП 20.13330), для быстрой внутренней прикидки.

1Ветровая нагрузка

Приближённая интерполяция по табл. 11.2 СП 20.13330

2Нагрузка на кронштейн

Горизонтальные ламели на подсистеме (доп. нагрузка, консоль в створе кронштейна)
Плечо момента считается от анкера: вылет кронштейна e + этот вылет
Ламель на вылете парусит сильнее плоской кассеты (эффект козырька/крыла) — ориентировочно 1.2–1.5, уточняйте по ТС профиля
1.0 — снег лежит свободно; если ламель у стены и возможен надув/скопление — берите больше (1.5–2 и выше)
Допустимая несущая способность кронштейна (из ТС)

3Проверка анкера

Основание (бетон/кладка), краевые и осевые расстояния анкер-специфичны — здесь не учитываются. Берите N_Rd/V_Rd уже с учётом понижающих коэффициентов из ETA конкретного анкера.

4Проверка несущего профиля

ΣИтоговая сводка

ПроверкаРасчётДопустимоИспользованиеСтатус
Инструмент даёт предварительную прикидку по нормативным формулам (СП 20.13330) и типовой методике проверки НВФ. Коэффициенты k(z) и c — приближённые табличные значения, аэродинамическое зонирование здания и параметры конкретного анкера/кронштейна/профиля здесь упрощены. Не заменяет расчёт, подписанный ГИП/сертифицированным инженером, и техническое свидетельство системы. Для объектов с высокой ценой ошибки — обязательна проверка специалистом.
